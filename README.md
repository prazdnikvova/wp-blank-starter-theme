# Blank — стартова тема WordPress

Власна стартова тема, з якої починалися нові сайти на WordPress: мінімальна розмітка, сітка Bootstrap, ACF-блоки, SCSS-структура й готовий модуль контактної форми. Проєкт 2021–2022. Історію відновлено приблизно: оригінальні дати файлів не збереглися.

Основа — [BlankSlate](https://github.com/tidythemes/blankslate) від TidyThemes (версія 2019, GNU GPL v3 або пізніша). Тема перейменована в Blank, функції отримали префікс `blank_`, шаблони спрощено під блокову верстку. Остання версія в історії — з робочого проєкту, де тема обросла блоками й стилями.

## Що додано поверх BlankSlate

- `blocks/register.php` — категорії блоків, приховування стандартних блоків Gutenberg, реєстрація ACF-блоків; `blocks/content-*.php` — дев'ять блоків: відступ, hero із зображенням ліворуч або праворуч, три варіанти CTA, список переваг, велика цитата, слайдер новин.
- `contact/` — контактна форма як ACF-блок: шаблон, стилі, скрипт і AJAX-обробник з відправленням через `wp_mail()`; адреси відправника й одержувача задаються в полях блока.
- `scss/` — структура стилів: базові, текстові, кольори сторінок, CTA-блоки, слайдери; `main.scss` збирає частини й задає палітру.
- `js/admin.js` — скрипт для редактора блоків: додає класи колонок Bootstrap (`col-lg-*`) у налаштування блоків; `js/editor.js` — палітра кольорів редактора.
- `functions.php` — підключення стилів і скриптів теми, Bootstrap-сітки, слайдера slick і скомпільованого SCSS, реєстрація меню, стилі адмінки.
- `style.css` — скидання стилів BlankSlate плюс службові класи теми.

Без змін від BlankSlate залишилися `404.php`, `author.php`, `comments.php`, `index.php`, `sidebar.php` і `readme.txt`; решту шаблонів переписано.

## Залежності, яких немає в репозиторії

- Bootstrap grid CSS (MIT): тема очікує `css/bootstrap-grid.css` і `css/bootstrap-grid.min.css`, скопіюйте їх з пакета Bootstrap 4.
- slick 1.8.1 (MIT): тека `js/slick/` з пакета slick-carousel.
- Advanced Custom Fields PRO — для блоків і контактної форми; комерційний плагін, не входить.
- `css/compiled/main.css` — результат компіляції `scss/main.scss`, збірка не зберігається.
- Зображення теми (`img/`, `screenshot.jpg`) не входять.
